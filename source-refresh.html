Coverage and limitations

    A successful check confirms what that source returned. It does not prove that the publisher's information is current. Publication dates, accepted place memberships and existing evidence dates remain separate.

    For changes awaiting review, open the latest run and download source-refresh-review. Review files are retained for 30 days. The next attempt will collect them again if unresolved. Historical run reports remain available in GitHub Actions.
